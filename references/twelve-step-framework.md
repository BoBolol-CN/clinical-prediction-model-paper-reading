# 预测模型文献阅读：12步拆解框架

用途：供研究者或AI阅读临床预测模型论文时使用，逐步还原研究流程、评价方法、提炼可迁移的方法学启示。以12步阅读框架组织问题，并以BMJ教程补充方法学依据。版本：2026-11-02。

本文件是一份通用的文献阅读说明。人数、终点、缺失率界限、算法和验证设计均从正在阅读的论文中提取；不内置任何特定研究课题的设置。

BMJ原教程共有13步；本框架保留前12步，将第13步的模型公开、复现和使用工具检查并入阅读收尾。适用于回归及机器学习预测研究；诊断、预后、模型更新和单独外部验证论文，按其实际任务调整，不要求每篇都重新开发模型。[^1]

## 🎯 使用方式与基本规则

以后提供论文时，可以直接使用下面这段指令：

> 请按《预测模型文献阅读：12步拆解框架》分析这篇论文。先读正文、图表和可获取的补充材料，还原作者实际的数据处理、建模与验证流程；再按12步逐项拆解。每一步分别说明作者做了什么、为什么这样做、方法有什么限制，以及具有哪些可迁移的方法学启示。核查支撑关键做法的参考文献，说明它们增加了哪些信息和你实际读到了哪里。未报告、未获取和推断必须标清，不能替作者补齐步骤。最后给出方法学启示、适用条件及尚待核查的问题。

执行时遵守以下规则：

1. **先还原，后评价。** 作者实际做法、作者给出的理由、阅读者的方法学解释分开写。
2. **以论文证据为准。** 每项关键结论附正文小节、表号、图号、补充材料页码或代码位置；有链接则附链接。
3. **未报告不等于没做。** 区分“明确报告”“未报告”“材料未获取”“阅读者推断”“不适用”。相互矛盾的正文、补充材料或代码需并列记录。
4. **查到具体做法。** 不止写“做了特征工程、LASSO、交叉验证”；必须说明改了哪些变量、筛选规则是什么、在哪份数据中完成、如何得到最终模型。
5. **保留比较条件。** 记录样本量、事件数、结局、预测时点、时间窗和验证方式，不能把不同条件下的AUC直接排榜。
6. **按证据讨论借鉴。** 高分期刊、较新年份或复杂算法不能替代方法评价；不因文章发表了，就将其全部做法视为推荐。
7. **只在适用时深入。** 没有竞争事件的研究不硬套Fine–Gray；没有调参的研究不强制寻找嵌套验证；没做DCA或SHAP也不自动判为缺陷。
8. **一次只讲用户指定的范围。** 若要求逐步讨论，先说明总体流程，再只展开指定步骤；研究方案设计仅在用户明确要求时开展。

每一步固定回答四件事：

| 记录层次 | 内容 |
|---|---|
| **作者做法与依据** | 方法、数字、设置、原文位置；作者是否解释原因 |
| **方法学评价** | 解决什么问题；优点、限制及适用条件 |
| **借鉴判断** | 可借鉴／有条件借鉴／不宜照搬／信息不足 |
| **待核查内容** | 缺失的设置、补充材料、关键方法引文 |

## 📋 开始前：先给论文定位

先用一张信息卡回答以下问题，再进入12步。不要一开始只关注算法排行榜。

| 项目 | 待提取内容 |
|---|---|
| **文献身份** | 完整题名、作者、期刊、年份、DOI、模型名称 |
| **研究任务** | 新模型开发／模型更新／外部验证／新增指标价值评估 |
| **临床问题** | 给谁、在什么时点、预测什么、预测多久、供谁使用 |
| **数据来源** | 队列／注册数据库／电子病历／试验；中心、地区、年份 |
| **样本构成** | 开发与各验证队列的人数、事件数；人数还是记录条数 |
| **结局形式** | 连续、二分类、时间至事件；是否有复合终点或竞争事件 |
| **方法路线** | 原始数据到最终模型的实际处理顺序 |
| **已读材料** | 正文、补充方法、图表、方案、代码；未获取材料 |

先用3—5句话概括全文，然后按原文还原一条流程。例如：

> 队列形成 → 划分开发与验证数据 → 缺失与特征处理 → 变量筛选／调参 → 拟合候选模型 → 内部评价与选择 → 最终重拟合 → 锁定模型 → 外部评价。

这只是阅读时的定位示例。作者实际顺序不同就如实写；缺了哪一环写“未报告”，不能将示例当作该论文已经完成的流程。

## 📚 12步逐项拆解

### 1．明确目标、查阅文献、制定研究计划

核心问题：作者究竟想解决哪个预测问题，为什么值得做？

需要查清：

- 目标人群、医疗环境、预期使用者；数据库里的患者能否代表这些人。
- 预测发生在入院、术前、出院还是随访中的某个时点；这个时点能取得哪些信息。
- 预测用于风险沟通、检查、治疗决策、随访管理，还是仅作方法探索；有没有明确下一步行动。
- 文献综述是否说明已有模型、已知预测因素和既往模型的局限；“尚无研究”的说法有何检索支持。
- 是否利用既往研究确定候选因素、非线性形式、交互关系及可能的缺失机制。
- 是否有研究方案、注册或公开的分析计划；哪些决定预先确定，哪些是看过数据后增加。
- 团队是否具有临床、方法和数据来源方面的知识；是否考虑实际使用者的需求。

这一部分包含三个层次：明确研究目标、了解既有模型与因素、形成研究计划。文献综述既服务于“为什么做”，也服务于“候选因素从哪里来”。[^1]

本步输出：一句完整的研究问题，以及作者声称的研究空白。评价时区分真正的临床需要、可迁移性问题和单纯更换算法。

### 2．选择开发新模型，还是验证／更新现有模型

核心问题：文章到底做了哪一种研究？

需要查清：

- 是否从头估计新模型；为什么现有模型不能满足目标人群或应用场景。
- 若验证已有模型，是否直接使用原来的公式、系数、预处理和风险计算规则。
- 若更新模型，改动属于再校准、重新估计部分或全部系数，还是增加新预测因素。
- 是否分别报告更新前和更新后的表现；更新后的模型是否再得到适当评价。
- 是否只是比较已有评分，或者用机器学习探索后生成一个新的简化评分。

阅读边界：在验证队列上重新估计系数，是更新或重新拟合，不能把更新后的成绩直接当作原模型的独立验证成绩。单独外部验证研究不需要重复完成全部开发步骤；应区分原模型做法与本次验证做法。[^1]

本步输出：明确研究类型、使用或更新的原模型，以及新旧模型的关系。

### 3．定义结局指标

核心问题：模型预测的具体事件或数值是什么，如何确认？

需要查清：

- 结局是连续数值、固定时间的二分类，还是时间至事件；“发生／不发生”的临床事件不等于研究一定采用普通二分类建模。
- 单一结局还是复合结局；逐项列出组成、严重程度、诊断标准、部位及是否只算首次事件。
- 随访起点、预测时间窗、事件日期、末次观察日期、删失规则及随访完整性。
- 结局来自病历、登记、电话随访还是独立裁定；不同中心的定义是否一致。
- 是否存在阻止目标事件发生的竞争事件；被计入复合终点、作为竞争事件，还是被当作普通删失。
- 已确认事件但日期不详、仅有年月或年份、同日多个事件、日期冲突如何处理。
- 多次事件只取首次，还是使用复发事件、多状态等不同框架。

阅读边界：终点名称相同不代表定义相同。尤其核对死亡是否并入复合终点；不要把“事件数多”建立在不同结局混算的基础上。不能把随访不足且暂未发病者直接视为整个预测窗无事件。[^1]

本步输出：可直接复述的结局定义，加一份“起点—目标事件—竞争事件—删失—时间窗”说明。

### 4．确定候选预测因素和测量方法

核心问题：最初为什么考虑这些因素，它们究竟如何测量？

需要查清：

- 候选池来自文献、指南、临床知识、既有评分，还是仅仅因为数据库有字段。
- 区分文献候选池、数据库可获得集合、进入数据驱动筛选的集合、最终保留集合；分别有多少变量。
- 定义、单位、编码、测量时点、多次测量取值规则、派生公式是否明确。
- 所有输入是否在预测时已知；不同中心及未来使用环境能否以相近方式取得。
- 是否报告全部候选因素及未纳入原因，包括未采集、缺失过多、定义不清、质量问题和信息重叠。
- 是否主要依据单因素P值筛选；是否把连续指标根据数据中的“最佳切点”分类。
- 重复信息是否处理：重复列、同一概念的不同表达、总分与条目、原始与派生指标。

必须检查的四项：**缺失率、定义、时间点、重复变量**。相互关联不等于必须删除一个；数据库有该字段也不等于适合在临床预测时使用。[^1]

连续指标重点记录：保留连续值、按临床标准分类、按数据找切点，分别属于什么做法。保留连续值不等于强制线性；复杂非线性也需要数据支持。[^2]

本步输出：候选因素形成过程。若论文信息足够，可整理“因素—依据—测量时点—可获得性—缺失比例—去留及理由”的候选因素台账，而非只抄最终模型的几项变量。

### 5．收集、检查数据及特征工程

核心问题：原始记录怎样变成可用于建模的患者级数据？

先核查数据形成：

- 数据来源、纳排流程、匹配规则、去重规则；一人多次住院或多条记录如何处理。
- 指标单位、编码、范围、日期顺序、中心间测量差异是否检查。
- 异常值如何判断；区分录入错误、真实极端值和无法确认的可疑值。
- 少见类别、低变异指标、未知状态及结构性缺失如何处理。
- 清洗是否可追溯；作者做的是一般错误核查，还是有额外资料支持的统计测量误差校正。[^1]

再逐项列出特征工程，不能只写“进行了预处理”：

| 方法 | 必须提取的具体信息 |
|---|---|
| **非线性转换** | 哪些变量；对数、二次项、RCS等形式；结点／自由度及依据 |
| **标准化与缩放** | 哪些变量；采用什么尺度；参数在哪份数据估计 |
| **类别编码** | 参考组、指示变量、有序或无序处理 |
| **派生指标** | 公式、原始输入、单位、取值时间 |
| **交互项** | 哪两个变量、采用何种形式、主效应是否保留 |
| **重复测量汇总** | 首次、最近、均值或变化量；允许的测量窗口 |
| **分类与分箱** | 切点来自临床标准还是本数据；分类造成的信息损失 |

尤其追问两个问题：作者凭什么认为需要非线性或交互？这些决定是在训练数据中探索、根据既有证据预设，还是看过验证成绩后修改？

解释时记住：RCS是连续变量的表达方式，可以放进回归模型，并非必须另换一种模型；交互项表示一个变量的预测关联随另一个变量而变，通常应同时考虑相应主效应。曲线有弯曲、SHAP图有变化，都不自动产生临床干预阈值。[^1][^2]

本步输出：逐项特征工程清单，写清“改了什么—为什么—增加什么复杂度—在哪份数据完成”。图形探索与预先指定的处理应分开记录。

### 6．考虑样本量和模型复杂度

核心问题：现有数据支持作者探索多少模型复杂度？

需要查清：

- 总样本、开发样本、各验证样本分别多大；分析单位是患者、住院记录还是图像等。
- 二分类结局的事件与非事件人数；生存结局的事件数、竞争事件、删失和随访支持。
- 特定时间窗内有多少事件、仍有多少人在观察；不能只看全随访期总事件数。
- 候选变量数、候选参数数及最终参数数；分类水平、非线性项和交互项增加了多少参数。
- 是否进行样本量计算、精度评估或模拟；所用公式、软件和假设是否适合研究的模型与结局。
- 变量筛选、反复比较算法及调参带来的额外不确定性，是否被讨论。
- 验证样本是否足以支持性能估计和置信区间，而非只证明开发样本足够。[^3]

参数计数示例：一个线性连续变量通常占1个参数；三分类变量通常占2个参数；3结点RCS通常占2个参数；交互项另计。这里是在说明回归参数，不能直接当作所有机器学习模型的复杂度公式。[^1][^3]

阅读边界：

- “每参数10个事件”不能单独证明样本量充分，也不能机械判定某篇论文只能纳入多少变量。
- 从较大的候选池筛出少数因素，不能当成一开始只考虑最终这些因素。
- 普通生存模型的样本量工具不自动适用于所有竞争风险模型，需核查推导和软件适用范围。
- 不能把“机器学习可能需要更多数据”改写为RF固定乘3、SVM固定乘10。[^1][^3]

本步输出：开发与验证的信息量，以及复杂度是否有依据；证据不足时写明无法确认，避免只凭一个事件／变量比下结论。

### 7．处理缺失数据

核心问题：缺了什么，如何处理，处理后如何分析？

需要查清：

- 总体及分中心缺失比例；缺失的是预测因素、结局状态还是事件日期。
- 缺失模式、可能原因及机制假设；某中心完全不测一项指标，与零散缺失如何区分。
- 删除患者、删除变量、完整病例分析、单次插补、多重插补或算法内置处理分别在哪里使用。
- 是否设定缺失率界限；阈值依据是什么；被排除的候选因素有没有报告。
- 多重插补的套数、迭代、变量类型、辅助变量、结局与随访信息、中心结构、非线性及交互如何处理。
- 是否有诊断、收敛和稳定性检查；是否进行有针对性的敏感性分析。
- 插补在数据划分前还是后，在重采样内还是外；训练与验证患者的信息如何隔离。
- 未来新患者缺少输入时如何预测，是否与验证时模拟的使用方式一致。[^4]

重点区分：

- 多重插补的多套数据来自同一批患者的不同合理填补，不是新增患者。
- MICE只是方法／工具名称；需看生成、使用了几套数据以及如何合并，不能仅凭软件名称认定执行了完整多重插补。
- 每折只插补一次的10折交叉验证，不等于同一数据的10套多重插补。
- 右删失、预测因素缺失、已知事件但日期未知，是不同问题。
- 开发分析中使用结局辅助插补，与实际应用时可否知道未来结局，是不同场景；不能利用验证患者未来结局填补输入后，声称模拟了实际部署表现。[^4][^5]

缺失率界限、插补套数等属于需要核查依据的研究设置，不是所有论文必须遵守的统一规定。

本步输出：完整缺失处理流程，尤其说明插补如何衔接筛选、建模、验证及实际使用；具体合并方式在第8、9步继续核查。

### 8．拟合预测模型：还原核心建模过程

核心问题：作者究竟怎样从候选因素得到可预测的模型？

逐个候选模型查清以下内容：

1. **算法与输出。** 具体模型、软件实现、预测目标；输出的是概率、某时点生存／累积发生概率，还是仅风险评分。
2. **变量进入方式。** 预设全部纳入还是先筛选；各模型是否使用同一候选池；不同模型的变量表达是否有合理依据。
3. **变量选择。** 单因素、逐步法、LASSO、Elastic net或其他方法；筛选发生在哪份数据、哪一层重采样中。
4. **调参。** 优化什么参数、搜索范围及方法、选择指标、次数和停止规则；关键设置未报告要明确标记。
5. **模型假设。** 例如比例风险、函数形式、交互、中心聚集结构；是否检查以及如何处理不满足的情况。
6. **竞争事件。** 若存在，模型是否真正预测目标事件的累积发生风险；只写“Cox”“RSF”“SVM”不足以确认处理方式。
7. **多重插补后的拟合。** 每套是否都建模；变量集合不一致如何解决；最终合并参数、模型预测还是其他对象。
8. **最终风险计算。** 模型如何给新患者输出一个风险；需要的系数、基线风险、预处理或集成规则是否齐全。[^1]

对常见做法作进一步拆解：

- LASSO直接作为预测模型，与“LASSO筛变量→再训练其他模型”是两条路线。后者需要评价整个流程，后续模型不会自动继承LASSO的系数收缩。
- 标准LASSO交叉验证主要选择惩罚强度λ；按入选频率或前若干名筛选属于另外的规则，需作者明确说明。
- 仅用线性形式进行筛选，可能漏掉主要呈非线性关系的信息；这不等于要求所有变量都加样条。[^6][^7]
- 惩罚、收缩和筛选不能消除样本不足，也不保证模型一定更准。[^7]
- 多套插补数据的变量选择需有衔接规则；MI-LASSO等方法有自己的模型和假设，不能仅凭名称推广到任意结局。[^8]
- 合并参数、合并患者预测、合并性能指标回答不同问题；Rubin规则包含不确定性的合并，不是对任何模型随意平均系数。[^4][^9]

本步输出必须具体到：输入哪些变量、如何表达、如何筛选、如何调参、在哪里拟合、最后如何预测。若作者使用标准未惩罚回归且方案固定，如实写明，无需替其添加机器学习流程。

### 9．评估模型预测性能与验证设计

核心问题：作者给出的成绩，来自哪份数据、怎样计算、能支持什么结论？

#### 9.1 评价了哪些方面

同时查看区分度、校准和总体预测误差；某项未报告时说明其对判断的影响。不能用显著HR或P值替代模型性能，也不能用AUC代替校准。[^10]

| 结局 | 区分与总体表现 | 校准重点 |
|---|---|---|
| **连续结局** | MSE／RMSE、R²等整体指标 | 预测与观察的系统偏差、校准线 |
| **二分类结局** | AUC；Brier score | 平均校准、截距／斜率、校准曲线 |
| **生存结局** | 适当的C-index、时间AUC、时间点或积分Brier | 指定时点，考虑删失 |
| **竞争风险结局** | 与目标事件及竞争风险相容的指标 | 比较预测与观察的累积发生概率 |

这张表提供阅读方向，不要求每篇报告全部指标。应记录指标的具体定义、估计方法、时间窗和不确定性，而不是只抄名称。[^1][^10]

校准图重点核查：

- 横轴是什么预测量；纵轴如何得到观察量；图例或正文是否与实际方法一致。
- 二分类观察比例、普通生存的`1−KM`、竞争风险的累积发生概率不可混用。
- 竞争风险的分组观察风险可用Aalen–Johansen估计；平滑曲线也需与删失和竞争风险相容的方法。
- 校准不仅是画一条45°参考线；还要查看实际拟合曲线、风险范围、数据支持及不确定性。
- 不能仅凭Hosmer–Lemeshow检验不显著，就认定校准良好。[^11][^12]

#### 9.2 到底做了哪种验证

| 名称 | 数据实际如何使用 | 阅读时要核实 |
|---|---|---|
| **表观评价** | 在拟合模型的同批数据评价 | 是否被误当成验证成绩 |
| **随机内部留出** | 同源数据随机分训练／测试 | 不能仅因叫test set就称外部验证 |
| **交叉验证** | 轮流训练和留出评价 | 折数、分折单位、每折重复的操作 |
| **Bootstrap** | 有放回重采样 | 用于乐观校正、置信区间还是稳定性 |
| **IECV** | 按医院等集群轮流留出 | 跨中心表现及异质性 |
| **外部评价** | 锁定模型用于未参与开发的患者 | 地理、时间或其他差异及开发独立性 |

不要只接受作者给的标签。时间划分应说明来源、目的和独立性，不能机械认为都无效或都等于充分外部验证；多中心开发、单中心验证也不构成逻辑矛盾。[^1]

#### 9.3 验证是否覆盖完整流程

- 分折／抽样单位是患者、住院、医院还是图像；同一患者相关记录是否跨训练和验证造成信息泄漏。
- 插补、标准化、非线性形式选择、变量筛选、超参数选择等，哪些在每轮训练数据中重新完成。
- 交叉验证用于调参、选择模型，还是仅评价固定方案；若同一结果既选方案又报成绩，是否说明选择造成的乐观性。
- 若采用嵌套交叉验证，内层选什么、外层评价什么；不能只写“嵌套”而不交代。
- 若不采用嵌套设计，最终未参与开发的评价由什么数据承担；不把“没有嵌套”本身当作一律不合格。
- 是否反复查看留出集或外部队列表现后修改方案；如有，评价角色已发生变化。
- 各折／各中心／各套插补结果怎样汇总；是合并预测再算性能，还是分别计算再合并；是否说明对应的评价目标。[^1][^9][^13]

区分两个常见误解：固定整套建模方案时，纯评价型交叉验证不自动改变最终全开发数据拟合的系数；但一旦用结果选择λ、RCS形式、RF参数、SVM参数或最终算法，它就参与了开发。变量不变并不代表方案完全固定。

#### 9.4 稳定性、跨中心表现与最终重拟合

- 是否检查重采样后变量、系数、预测值或性能的变化；稳定性与平均性能是不同问题。[^14]
- IECV留出的是中心等集群，不是逐患者留一；各中心事件数及性能不确定性是否报告。[^15]
- 验证后在哪些数据上重拟合最终模型；“全部开发数据”不能含糊地扩大为另外留出的外部队列。
- 外部表现下降时，是否比较患者构成、事件风险、随访、变量定义及测量方式，而非只归因于算法。
- 再校准或更新后是否与原模型的外部成绩分开；一次验证成功不能证明适用于所有环境。[^1]

本步输出：验证设计说明和性能结果表。每个性能数字至少绑定“模型、队列、时间点、指标定义、估计值及区间”，避免混写训练、交叉验证和外部成绩。

### 10．确定最终模型

核心问题：为什么最终采用这一套模型，选择过程是否可信？

需要查清：

- 预先指定主模型、其余仅比较，还是多种候选模型经过评价后选择；两种设计不能混写。
- 依据什么数据选模型；优先指标是否预先确定，是否兼顾校准、总体误差、稳定性和实际使用成本。
- 性能差异大小及不确定性如何；有没有仅因AUC高一点便宣布“明显优越”。
- 不同算法是否在相同队列、结局和评价条件下比较；变量输入及调参资源是否合理。
- 表现相近时，是否考虑更简单、容易实现的模型；复杂不保证更好，简单也不保证更准。[^1][^16]
- 选择后是否用全部开发数据按确定方案重拟合，并锁定预测流程。
- 是否进一步简化成评分、分箱或删除变量；简化版本是否重新评价，不能直接沿用原模型成绩。

本步输出：候选模型如何变成最终模型的决策依据。不能替作者假定一定经过“多算法竞赛”，也不能把已经进行的算法选择改写为预设主模型。

### 11．决策曲线分析与临床用途

核心问题：预测结果准备改变什么行动，作者有什么证据说明这样做有价值？

先查行动，再看曲线：

- 风险升高后采取什么行动：检查、治疗、监测或其他措施；是否只是风险沟通。
- 阈值概率及合理范围来自指南、临床权衡、患者偏好，还是事后挑选。
- 比较哪些策略：模型指导、全部行动、全部不行动、现有做法或其他模型。
- 净收益在哪个队列、哪个时间点评价；是否控制乐观偏倚。
- 生存或竞争风险资料是否使用相应方法，不能直接把全随访“发生过／没发生过”套入普通二分类DCA。[^17][^18]

普通二分类净收益的基本形式是：`TP/N − FP/N × pt/(1−pt)`，其中`pt`为行动阈值。扣除的是按阈值加权的假阳性，不是真阴性；生存和竞争风险资料还需相应估计方法。[^18]

阅读边界：DCA不能寻找最佳临床阈值；没有指南规定的单一阈值，也不意味着绝对不能做DCA，关键是有可解释的行动和阈值范围。未做DCA时应结合研究用途评价，不自动判为不完整。[^17]

另行查看临床呈现：是否提供计算器、网站、评分或使用说明；输入能否实际取得。工具可运行、DCA显示潜在净收益、真实应用改善患者结局，是不同层次的证据。[^1]

本步输出：行动—阈值—比较策略—净收益证据，以及应用工具实际能做什么。

### 12．评估单个预测因素的预测能力：可选

核心问题：作者在解释哪一种“重要性”，这种解释能说明什么？

| 方法 | 实际操作 | 回答的问题 |
|---|---|---|
| **回归结果** | 解释系数、效应曲线及区间 | 在该模型条件下如何关联 |
| **删除后重拟合** | 比较包含与不含变量的流程 | 去掉该信息损失多少预测能力 |
| **置换重要性** | 打乱变量后评价固定模型 | 当前模型有多依赖这项信息 |
| **SHAP** | 分解预测相对参考值的差异 | 变量如何贡献于该次预测 |

前两类与后两类不是同一个问题；置换通常不重新拟合，而删变量比较需要重新拟合并适当验证。[^1][^19][^20]

需要查清：

- 分析对象是最终模型还是中间模型；使用哪个队列、哪个时间点及哪个输出尺度。
- SHAP解释的是绝对风险、对数风险、原始分数还是其他输出；参考背景如何选择。
- 回归系数的单位是否可比；非线性及交互是否作为相关模型项整体解释。
- 相关变量是否互相替代或分摊重要性；重要性低是否被误解为医学上无价值。
- 解释是全局还是针对某个患者；“不同人群的预测风险展示”是否被误称为亚组预测性能验证。
- 是否根据解释结果再次删变量或找切点；若改变模型，是否重新验证。

阅读边界：SHAP不是专门找截断值的方法；系数大、重要性高、关联显著，都不能单独证明改变该因素就能改善结局。共线性可能使系数和入选变量不稳定，不能将“整体预测仍可能不错”理解为所有共线性问题都可忽略。[^1][^20][^21]

本步输出：解释方法、解释对象、得到的预测层面信息及其限制。无需为了完成这一步强行增加因果研究。

## 🔗 关键引文怎样继续读

每次阅读不止摘抄主文中的引文编号，也不默认无差别阅读全文所有引用。优先核查决定方法选择和可借鉴性的参考文献：

2. 非线性、交互、变量筛选的依据及具体实现。
3. 样本量方法，尤其涉及特殊结局或复杂模型时。
4. 多重插补与筛选、重采样、性能合并的衔接方法。
